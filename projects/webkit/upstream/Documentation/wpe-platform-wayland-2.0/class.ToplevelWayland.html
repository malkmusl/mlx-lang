A WPEToplevel implementation for Wayland.

WPEToplevelWayland is the WPEToplevel implementation used by WPEDisplayWayland. It is backed by an xdg_toplevel and its Wayland surface can be accessed with wpe_toplevel_wayland_get_wl_surface().
