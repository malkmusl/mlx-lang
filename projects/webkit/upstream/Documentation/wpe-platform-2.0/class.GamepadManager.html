Tracks the available gamepads.

WPEGamepadManager is an abstract class that platform implementations derive to track the set of connected WPEGamepad devices. Create the manager for a display with wpe_display_create_gamepad_manager().

It notifies device hotplugging with the WPEGamepadManager::device-added and WPEGamepadManager::device-removed signals.
