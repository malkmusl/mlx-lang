A keyboard mapping.

WPEKeymap is an abstract class that platform implementations derive to translate between hardware keycodes and key symbols, and to track the state of modifier keys. Get the keymap of a display with wpe_display_get_keymap().

Use wpe_keymap_get_entries_for_keyval() and wpe_keymap_translate_keyboard_state() to convert between keycodes and key symbols.
