A monitor connected to a WPEDisplay.

WPEScreen is an abstract class that platform implementations derive to represent a monitor. Enumerate the screens of a display with wpe_display_get_n_screens() and wpe_display_get_screen().

A screen exposes its position, size, physical size, scale and refresh rate, and provides a WPEScreenSyncObserver to be notified on vertical sync.
