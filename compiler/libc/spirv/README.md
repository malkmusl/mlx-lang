# mlx-spirv's headers

SPIR-V's headers for the C++ compiled here (ANGLE's translator, which
writes SPIR-V for its Vulkan backend): `spirv/unified1/spirv.hpp`
(namespace `spv`) and `spirv/unified1/GLSL.std.450.h`, made by
mlx-cheaders of `api/` (`./mlx build spirv`, into mlx-out/include/mlx-spirv).
There is no library.

`api/spirv.mlx` and `api/glsl_std_450.mlx` are generated by `generate.sh`
(`generate.mlx`, with std.spirv.materialize's reading of the grammar) from
std/registry/spirv's grammars, as SPIRV-Headers' generator makes its
headers: the value enumerations (`StorageClassInput`), each bit
enumeration as `...Shift` and `...Mask` with the mask's `|`, `&`, `^` and
`~`, `Op`, every alias the grammar names, and `Id`, `MagicNumber`,
`Version`, `Revision`, `OpCodeMask`, `WordCountShift` as constants of the
namespace (`const c_namespace = "spv"`). tools/check_mlx_vulkan.sh checks
them.
